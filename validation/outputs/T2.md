# T2 — Palmer Park Tool Library: public browse & reserve page

## 1. Design Brief

```
DESIGN BRIEF
- Use case: Public phone-first page where residents (mostly first-timers) browse a neighborhood
  tool-lending catalog by photo/category/availability and reserve tools for Saturday pickup.
- Pattern + variant: shopping-journey / category listing (photo-led retail), executed with the
  lists-and-grids photo-card-gallery row idiom; reservation rail = the pattern's cart-as-layout-state.   [Stage 1]
- Recipe: Dark Editorial (first-time-public × warm-human; no stated constraint argues for the
  Premium Editorial alternate)  ·  Density: 2 (editorial — hero ≈45% of first viewport, ~4 photo
  cards + rail per desktop view, photo ≈60% of card height, EVEN_MORE canvas padding)                    [Stage 2]
- Palette (5+ hexes): page + hero + band cards #333F48 (seamless), content cards #394c5a (one step
  lighter, flat, borderless), brand/accent #f7d027 amber (STRICT interactivity monopoly: active
  category chip, PICKED tag, check glyph, browse-all link, confirm CTA), semantic #6ba547 available-
  green (dark #0F2A05 text for ≥4.5:1) + #333F48 due-back chips on photos, text #ffffff (auto-invert
  on dark fills) + #A9BAC4 muted eyebrows/meta, billboard placeholder #2C363E.
- Header treatment: poster hero in the header slot — same-hex borderless card, page title killed;
  LIGHT H1 sentence + how-it-works step trio + divided trust-stat trio (148 tools · 312 neighbors ·
  $0) instead of a photo billboard or gray title bar.
- Signature moves (≥3, from recipe or anti-corporate menu):
  1. Tonal zoning / go dark (recipe move + menu #5) — headerContentLayout(backgroundColor:"#333F48")
     with flat #394c5a cards, showBorder:false, no shadows anywhere; zones are tint steps, not chrome.
  2. Photo-first cards with status riding the photo (menu #16) — cardLayout(padding:"NONE") ⊃
     billboardLayout(height:"SHORT_PLUS") + a!fullOverlay(alignVertical:"TOP", style:"NONE") tagField
     that swaps AVAILABLE→PICKED→DUE per state.
  3. Accent = interactivity (menu #9) — #f7d027 appears ONLY on tappable/selected things; levers:
     tagItem(backgroundColor/textColor) forks, richTextIcon(color) invisible-twin toggle,
     cardLayout(style:"#f7d027") confirm CTA as the page's single loud fill (no a!buttonWidget at all).
  4. Segmented category control from tagField + dynamicLink (menu #21) — forEach chips, selected
     amber fill, ghost #ffffff2e unselected fills tuned for the dark canvas.
  5. Kill the page title / poster hero (menu #12) — headingField(fontWeight:"LIGHT", headingTag:"H1")
     responsive LARGE→MEDIUM_PLUS + hand-built divided stat trio (cookbook 5.8) doing the trust work.
- Deliberately omitted: free-text search. First-timers on phones browse faster by category chip than
  by keyboard; the page curates 8 popular tools per category and routes the long tail through the
  "BROWSE ALL 148 TOOLS" link to a records-powered full-catalog list one click away.
```

```
            └─ CARD(rail, #394c5a, pad STANDARD, borderless)

               ├─ EMPTY STATE (no picks): plus-circle EXTRA_LARGE pale #A9BAC4 + invite sentence
               ├─ PICKED ROWS ×picked: CARD(#ffffff14, SEMI_ROUNDED, link=remove) [name + cat | ✕]

               └─ fine print SMALL #A9BAC4 (free · photo ID · late fee)
```
