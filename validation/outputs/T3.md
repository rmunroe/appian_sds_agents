# T3 — Quarterly OR Performance (Executive Dashboard)

Selector run (recorded before any other reading):
- **Stage 1**: review results monthly/quarterly + aggregates & trends ONLY + desktop/tablet → **S3 dashboards (executive)**.
- **Stage 2**: cadence `monthly-exec` × temperature `clinical-technical` (surgery/health) → **Calm Clinical, exec density** (primary kept; no stated constraint favoring the Executive Clarity alternate). Density: executive variant 1–2, shifted +1 toward Calm Clinical's stance of 3 → **2**.

---

## 1. Design Brief

```
DESIGN BRIEF
- Use case: Chief of surgery reviews quarterly OR utilization, case volume, and staffing KPIs
  at the monthly leadership meeting — aggregates and trends only, no row-level data; desktop + tablet.
- Pattern + variant: dashboards / executive                       [Stage 1: S3]
- Recipe: Calm Clinical, exec density  ·  Density: 2              [Stage 2: monthly-exec × clinical-technical]
  (evidence: 8 airy modules total, 5-KPI single masthead, zero grids, card padding MORE, row margins MORE)
- Palette (5+ hexes): page #F0F6F7 cool tint · cards #FFFFFF with #DCE6E8 borders (SEMI_ROUNDED,
  no shadow) · deep anchor #0E3842 (header band) · brand/secondary #1E798F (chart hero series,
  on-track bullet bars, equation stamps) · action accent #C22966 (the ONE solid button, nothing else) ·
  quiet context data #a4c2f4 / #cfe2f3 · semantic POSITIVE/NEGATIVE tokens rationed to delta glyphs
  and the single staffing breach · text STANDARD / SECONDARY tokens.
- Header treatment: three flush full-bleed bands in the header slot — deep-teal #0E3842 identity band
  (eyebrow + H1 at REGULAR weight + lone SOLID "Export Board Pack") → white 5-KPI masthead as ONE
  dividered card, not five boxes → #DCE6E8 filter band (quarter / campus / service line + data-currency
  note pinned right).
- Signature moves (≥3):
  1. Full-bleed band architecture — teal card + white KPI card + filter card stacked flush in the
     header slot (lever: header-slot a!cardLayout siblings, style hex fills, marginBelow "NONE" ×2).
  2. Bordered-not-shadowed cards, the Calm Clinical corpus exception (lever: showBorder true,
     borderColor "#DCE6E8", shape "SEMI_ROUNDED", showShadow false on every content card).
  3. Bullet targets with divider-as-target-tick (lever: paired a!progressBarField THICK in a
     spacing "NONE" + showDividers columnsLayout, stackWhen NEVER; POSITIVE spill when volume beats
     plan, all-NEGATIVE breach bars on RN vacancy — red's only home on the page).
  4. One teal ramp on every chart + interpretation beside data (lever: a!colorSchemeCustom
     {#0E3842, #1E798F, #a4c2f4, #cfe2f3} page-wide; hero #1E798F vs muted #a4c2f4 target series on
     the trend line; a one-line SMALL/SECONDARY verdict under each chart).
  5. Executive equation strip — In-Room ÷ Staffed = 78.4% (lever: TINY transparent stamps,
     EXTRA_NARROW "÷"/"=" operator columns, MEDIUM_PLUS values) so the headline math is auditable.
- Deliberately omitted: any case-level or surgeon-level grid and all drill-in links — the brief is
  aggregates-only for a board room; the executive variant sets grid share of viewport to ≈0%, and
  drill-down belongs to the analytical workspace, not this page. (Also no photo billboard: clinical
  register, data is the hero.)
```

Register notes: Calm Clinical's "no all-caps anywhere" is honored — eyebrow labels demote via SMALL +
SECONDARY + title case, never caps. Delta glyphs (▲/▼) carry color; delta digits stay neutral
(nonprofit KPI-band grammar). Exactly one SOLID button (#C22966). Equal thirds are deliberate: the
executive variant's rule — peer metric families (Utilization · Volume · Staffing) get peer weight.

```
│  │     teal ramp ) + verdict line

│        ×4 roles ) + verdict line

│       ── #DCE6E8 rule ── "Unused prime time 2,696 hrs ≈ 940 case-equivalents" SMALL SECONDARY
└─ footer note SMALL SECONDARY centered — meeting date · sources · metric definition
```

Site settings: page width **Wide** (chart-dense view page; tablet landscape keeps the 3-up rows).
Tablet behavior: TABLET_LANDSCAPE holds all 3-up rows; TABLET_PORTRAIT stacks both [1:1:1] rows and
the filter band; masthead stays 5-across until PHONE, where columns stack and dividers turn off.
