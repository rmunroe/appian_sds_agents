# R1 — Gate Rebooking Cockpit (IRROPS)

## 1. Design Brief

```
DESIGN BRIEF
- Use case: Airline gate agent works a cancelled-flight rebooking queue — pick passenger, compare
  alternate-flight seat inventory, commit, keep the standby list moving; shared desktop terminal,
  time pressure, keyboard-heavy.
- Pattern + variant: lists-and-grids / worklist (S8), executed as a list-detail pane split
  (variant 8) so the agent never navigates away from the queue.   [Stage 1]
- Recipe: Ops Control (daily-operator × clinical-technical; alt Calm Clinical rejected — this is a
  triage tool, not a reading tool)  ·  Density: 4 (masthead + 8 queue cards + 3 flight cards +
  36-cell seat map + 8 standby rows per viewport; SMALL metadata; DENSE side-by-side spacing)
- Palette (5+ hexes): page/panes #f4f2f1 warm greige; cards #ffffff shadow-not-border; brand/accent
  ACCENT token (site brand — selection bars, segmented filter, selected seat, the one SOLID button);
  semantic NEGATIVE token = AT RISK only, cleared-standby duotone #d7f3e0/#459b20, cabin-inventory
  duotone chips #d9d2e9/#674ea7 (First) + #d7e5f3/#3d85c6 (Economy+), tier pastels #eccd5f (1K) /
  #d19fcb (Gold) / #9db6d0 (Silver); text #54514e headings / #666666 metadata.
- Header treatment: none — no page title, no colored band (Ops Control prohibition). The queue
  rail is crowned by a white masthead card: "MR 2214 · CANCELLED" + flush THIN progress strip
  (24 of 58 rebooked) riding the card's bottom edge.
- Signature moves (≥3, from recipe or anti-corporate menu):
  1. Whole-card worklist rows + decorative-bar selection — every queue row and flight option is one
     a!cardLayout(link: a!dynamicLink) with shadow; selected sibling gets decorativeBarPosition
     "START" in ACCENT, unselected twins painted "#ffffff" so x-offsets never shift.
  2. Hand-built seat map from the calendar-grid recipe — a!columnsLayout(spacing:"NONE") rows of
     tiny SEMI_ROUNDED seat cards: open = bordered white + STRONG, taken = #f3f3f3 fill + no link,
     selected = ACCENT fill (auto-white text); row number rides the aisle column. No seat dropdown.
  3. Pastel chip vocabulary (color as vocabulary, not decoration) — tier tags #eccd5f/#d19fcb/#9db6d0,
     cabin inventory duotones, gray SECONDARY = done/Economy, green duotone = standby CLEARED, via
     a!tagItem(backgroundColor, textColor).
  4. Red rationed to one meaning — NEGATIVE appears only on AT RISK queue tags (misconnect risk);
     the cancellation itself is a calm SECONDARY tag: the agent already knows the flight cancelled.
  5. Kill the page title + flush progress masthead — orientation comes from the cancelled-flight
     card and its a!progressBarField(style:"THIN", color:"ACCENT") recovery strip, not a gray title.
- Deliberately omitted: all imagery, billboards, and charts — under IRROPS pressure every pixel is
  queue state or seat state; brand romance and KPI art would slow the 30-second rebook loop
  (Ops Control: "a doing UI, not a reading UI").
```

## 2. Layout skeleton

```
IF PHONE / TABLET_PORTRAIT → HEADER-CONTENT fallback (coded non-pane variant, see SAIL §mobile:
   masthead → dense queue rows → passenger band → flight cards → auto-assign seat note → buttons)
ELSE:
PANE-LAYOUT (root, full-height, independently scrolling; showDividers)
├─ PANE[rebook queue] width=MEDIUM bg=#f4f2f1 pad=STANDARD
│  ├─ CARD(masthead, white shadow, pad NONE → inner padded block + flush strip)
│  │  ├─ SBS: "MR 2214" LARGE BOLD + TAG "CANCELLED" (SECONDARY) | "ORD → DEN" pinned
│  │  ├─ meta SMALL #666: "Sched 16:55 · Gate B12 · Crew" 
│  │  ├─ SBS: "24 of 58 rebooked" STRONG | "34 open" SECONDARY (MINIMIZE)
│  │  └─ PROGRESS(THIN, ACCENT, 41%) flush to card bottom
│  └─ SECTION H3 "REBOOK QUEUE" (SMALL SECONDARY caps)
│     ├─ TAGS segmented filter [ALL | AT RISK | DONE] — selected=ACCENT, else #fff, working showWhen
│     └─ a!forEach CARD(passenger, shadow, ROUNDED, bar START: ACCENT sel / #fff twin, whole-card link)
│        ├─ SBS: name STRONG (+party) | tier TAG + status TAG (AT RISK NEGATIVE / DONE SECONDARY) pinned
│        └─ meta SMALL #666: PNR · cancelled seat · note   (×8 rows, at-risk sorted first)
├─ PANE[work surface] width=AUTO bg=#f4f2f1 pad=STANDARD
│  └─ COLUMNS [AUTO empty (DESKTOP+ only) : WIDE_PLUS : AUTO empty] — capped measure on wide terminals
│     ├─ CARD(passenger band, white shadow): headingField "Kowalski, Dana" LARGE + 1K TAG
│     │  ├─ COLUMNS ×4 eyebrow/value: PNR | CANCELLED SEAT | BAGS | ONWARD
│     │  └─ clock-o line: "MR 448 departs DEN 21:10 — arrival needed by 20:40" SMALL #666
│     ├─ SECTION H3 "ALTERNATE FLIGHTS"
│     │  └─ a!forEach CARD(flight, shadow, bar START sel/#fff twin, whole-card link) ×3
│     │     ├─ SBS: "MR 2288" STRONG | route SMALL | spring | "18:20 → 19:58" STRONG pinned
│     │     ├─ SBS: check/clock + connection verdict SMALL | spring | gate·equip SMALL pinned
│     │     └─ SBS: cabin chips [F 2·plum][W 6·blue][Y 23·gray] | spring | load SMALL pinned
│     ├─ SECTION H3 "SEAT MAP · MR 2288 · 737-800"
│     │  └─ CARD(white shadow): 6× COLUMNS(spacing NONE, stackWhen NEVER)
│     │     [A][B][C] [row# aisle] [D][E][F] — cell cards per state; legend line below
│     └─ BUTTONS: SOLID "Rebook On MR 2288 · Seat 21C" | OUTLINE "Skip" | OUTLINE "To Standby"
└─ PANE[standby] width=MEDIUM bg=#f4f2f1 pad=STANDARD
   ├─ SECTION H3 "STANDBY · MR 2288" + "8 listed · 3 seats releasable" SMALL
   ├─ CARD(white shadow): a!forEach SECTION(divider BELOW) rows:
   │  SBS: position STRONG | name STRONG + meta SMALL | CLR·seat TAG (green duotone) pinned  (×8)
   ├─ CARD(action, shadow, link): stamp(plus, #6fbb62) + "Add Walk-Up to Standby"
   └─ clock-o note SMALL #666: "Unclaimed seats release 18:10 (T-10)"
```
